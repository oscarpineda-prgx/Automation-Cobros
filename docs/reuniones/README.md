# Reuniones

Una nota por reunión. Nomenclatura: `NNN-YYYY-MM-DD-tema.md`
(`NNN` = número consecutivo de reunión).

Cada nota sigue la plantilla de [`_PLANTILLA.md`](_PLANTILLA.md).

📁 **Las transcripciones íntegras están en [`transcripciones/`](transcripciones/)** — se
conservan sin editar como respaldo de las notas analizadas.

> **Regla:** todo acuerdo, regla de negocio o definición de columna que salga de una
> reunión se copia también a [../LOGICA_NEGOCIO.md](../LOGICA_NEGOCIO.md) §9, para que la
> fuente de verdad sea única.
